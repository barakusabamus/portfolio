# WebENS Portfolio

🎨 Современное портфолио веб-разработчика с безумными анимациями

## 🚀 Особенности

- ✨ Canvas анимация с частицами
- 🎭 Glitch эффекты
- 🌊 Плавные градиенты и переходы
- 💎 Прозрачность и blur эффекты
- 📱 Полностью адаптивный дизайн
- 🎯 3D tilt эффект на карточках
- ⚡ Кастомный курсор
- 🔄 Typing эффект
- 🎨 Синяя цветовая палитра

## 📦 Технологии

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript
- Canvas API

## 💻 Локальный запуск

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/portfolio.git

# Перейти в директорию
cd portfolio

# Запустить локальный сервер
python -m http.server 8000

# Открыть в браузере
http://localhost:8000
```

## 📂 Структура проекта

```
portfolio/
```
